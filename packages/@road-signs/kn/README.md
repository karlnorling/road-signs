# @road-signs/kn

Road signs for Saint Kitts and Nevis — a TypeScript registry with typed lookup helpers.

> **No signs yet.** This package is scaffolded but its registry is still empty,
> so `getAllSigns()` returns `[]`. Contributions of sources are welcome —
> see [the coverage notes](https://karlnorling.github.io/road-signs/countries/kn/).

## Install

```sh
npm install @road-signs/kn
```

## Usage

```ts
import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/kn';

signs; // the whole registry
```

## Notes

No SVG assets currently on Wikimedia Commons. Saint Kitts and Nevis uses a British-derived sign system under the Road Traffic Act.
