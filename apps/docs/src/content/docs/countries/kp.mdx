The `@road-signs/kp` package contains North Korean road signs (DPRK road sign system, 도로 표시).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/kp
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `priority` | Priority | Priority and right-of-way signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service / Additional | Information, service, and additional signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/kp';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("example-sign");

    // By sign code
    const s = getSignByCode("one-way-road");

    // All mandatory signs
    const filtered = getSignsByCategory('mandatory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/kp';
    import { RoadSign } from '@road-signs/react';

    const mandatory = getSignsByCategory('mandatory');

    export default function MandatoryGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {mandatory.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/kp';
    import { RoadSign } from '@road-signs/vue';

    const mandatory = getSignsByCategory('mandatory');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in mandatory" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
