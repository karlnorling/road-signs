The `@road-signs/mu` package contains Mauritius road signs (Traffic Signs Regulations 1990 — UK-derived system).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/mu
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `priority` | Priority | Priority and right-of-way signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service / Additional | Information, service, and additional signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/mu';

    // Example below uses the real MU sign "curve-to-the-right" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("curve-to-the-right-curve-to-the-right");

    // By sign code
    const s = getSignByCode("curve-to-the-right");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/mu';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function MUGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/mu';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
