The `@road-signs/la` package contains Laos road signs from the **Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/la
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service / Additional | Information, service, and additional plate signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/la';

    // Example below uses the real LA sign "V1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("v1-curve-to-left");

    // By sign code
    const s = getSignByCode("V1");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/la';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function LAGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/la';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
