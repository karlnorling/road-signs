## Quick facts

| Field | Value |
| ----- | ----- |
| Drive side | Right-hand |
| Language(s) | Arabic |
| Regulator | Ministry of Transport |
| Standard | Vienna Convention / Italian-influenced |

{/* QUICK_FACTS:END */}

The `@road-signs/ly` package contains Libya road signs from the **Vienna Convention (Arabic-only signage)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/ly
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Regulatory | Regulatory and prohibition signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/ly';

    // Example below uses the real LY sign "libyan-stop-sign" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("libyan-stop-sign-libyan-stop-sign");

    // By sign code
    const s = getSignByCode("libyan-stop-sign");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/ly';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function LYGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/ly';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
