The `@road-signs/ca` package contains Canadian road signs from the **Manual of Uniform Traffic
Control Devices for Canada (MUTCDC)**, published by the Transportation Association of Canada
(TAC). Signs are sourced from Wikipedia / Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/ca
```

## Sign categories

| Category | MUTCDC series | Description |
| -------- | ------------- | ----------- |
| `warning` | WA/WB series | Warn drivers of conditions ahead — diamond-shaped, yellow/black |
| `regulatory` | RA/RB series | Inform drivers of laws and regulations — white/red/black |
| `information` | GA/GB/GC/IM series | Destination, guide, and motorist services — green/blue |
| `school` | WC series | School zone and pedestrian crossing — fluorescent yellow-green |
| `temporary` | TC series | Temporary traffic control / work zone — orange |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/ca';

    // All signs
    signs.length;

    // By slug ID
    const stop = getSign('rb-1-stop');

    // By MUTCDC code
    const yield_ = getSignByCode('RB-2');

    // All warning signs
    const warnings = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/ca';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/ca';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { CASign, CACategory } from '@road-signs/ca';

type CACategory =
  | 'information'
  | 'regulatory'
  | 'school'
  | 'temporary'
  | 'warning';

interface CASign {
  id: string;        // e.g. "wa-1-curve-right"
  code: string;      // e.g. "WA-1"
  name: string;      // e.g. "Curve Right"
  description: string;
  category: CACategory;
  svg: string;       // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
