The `@road-signs/be` package contains Belgium road signs from the **Code de la route / Verkeersreglement**, Belgium's road traffic code which follows the Vienna Convention.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/be
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Hazard warnings |
| `priority` | B series | Right-of-way signs |
| `prohibitory` | C series | Prohibitions and restrictions |
| `mandatory` | D series | Compulsory actions |
| `information` | E–X series | Information and direction signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/be';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a1-danger-bend-right");

    // By sign code
    const s = getSignByCode("A1");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/be';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">

    ```vue
    </script>

      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { BESign, BECategory } from '@road-signs/be';

type BECategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface BESign {
  id: string;          // e.g. "a1-danger-bend-right"
  code: string;        // e.g. "A1"
  name: string;
  description: string;
  category: BECategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
