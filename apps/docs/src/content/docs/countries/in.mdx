The `@road-signs/in` package contains Indian road signs from the **Motor Vehicles Act (IRC:67 standard)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/in
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Cautionary | Cautionary signs — hazard warnings |
| `prohibitory` | Mandatory | Mandatory signs — prohibitions and regulations |
| `information` | Informatory | Informatory signs — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/in';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("w1-sharp-bend");

    // By sign code
    const s = getSignByCode("W1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/in';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { INSign, INCategory } from '@road-signs/in';

type INCategory =
  | 'information'
  | 'prohibitory'
  | 'warning';

interface INSign {
  id: string;          // e.g. "w1-sharp-bend"
  code: string;        // sign code, e.g. "W1"
  name: string;
  description: string;
  category: INCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
