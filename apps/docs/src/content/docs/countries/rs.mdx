## Quick facts

| Field | Value |
| ----- | ----- |
| Drive side | Right-hand |
| Language(s) | Serbian |
| Regulator | AMSS |

{/* QUICK_FACTS:END */}

The `@road-signs/rs` package contains Serbian road signs from the **Zakon o bezbednosti saobraćaja**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/rs
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | II series | Hazard warnings |
| `priority` | III series | Right-of-way and prohibitions |
| `prohibitory` | III series | Prohibitions and restrictions |
| `mandatory` | IV series | Mandatory actions |
| `information` | V series | Information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/rs';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("ii1-sharp-bend");

    // By sign code
    const s = getSignByCode("II-1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/rs';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/rs';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { RSSign, RSCategory } from '@road-signs/rs';

type RSCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface RSSign {
  id: string;          // e.g. "ii1-sharp-bend"
  code: string;        // sign code, e.g. "II-1"
  name: string;
  description: string;
  category: RSCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
