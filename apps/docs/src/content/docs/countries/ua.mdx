The `@road-signs/ua` package contains Ukrainian road signs from the **Правила дорожнього руху (PDR) — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/ua
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 1.xx | Попереджувальні знаки — hazard warnings (decimal codes, e.g. 1.1, 1.2) |
| `priority` | 2.xx | Знаки пріоритету — right-of-way signs |
| `prohibitory` | 3.xx | Заборонні знаки — prohibitions and restrictions |
| `mandatory` | 4.xx | Наказові знаки — mandatory actions |
| `information` | 5.xx | Інформаційні знаки — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/ua';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("1-1-sharp-bend");

    // By sign code
    const s = getSignByCode("1.1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/ua';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/ua';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { UASign, UACategory } from '@road-signs/ua';

type UACategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface UASign {
  id: string;          // e.g. "1-1-sharp-bend"
  code: string;        // sign code, e.g. "1.1"
  name: string;
  description: string;
  category: UACategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
