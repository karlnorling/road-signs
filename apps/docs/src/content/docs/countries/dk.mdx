The `@road-signs/dk` package contains Denmark road signs from the **Færdselsloven**, Denmark's road traffic act which follows the Vienna Convention.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/dk
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Advarselstavler — hazard warnings |
| `priority` | B series | Vigepligtstavler — right-of-way |
| `prohibitory` | C series | Forbudstavler — prohibitions |
| `mandatory` | D series | Påbudstavler — compulsory actions |
| `information` | E–F series | Oplysningstavler / Vejledningstavler |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/dk';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a21-dangerous-bend");

    // By sign code
    const s = getSignByCode("A21");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/dk';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { DKSign, DKCategory } from '@road-signs/dk';

type DKCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface DKSign {
  id: string;          // e.g. "a21-dangerous-bend"
  code: string;        // e.g. "A21"
  name: string;
  description: string;
  category: DKCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
