The `@road-signs/tw` package contains Taiwan road signs from the **Road Traffic Safety Rules (道路交通標誌標線號誌設置規則)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/tw
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | 警告標誌 — hazard warnings |
| `prohibitory` | Regulatory | 禁制標誌 — prohibitory and regulatory signs |
| `mandatory` | Instruction | 指示標誌 — mandatory instruction signs |
| `information` | Guide | 指引標誌 — guide and information signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/tw';

    // Example below uses the real TW sign "A1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a1-taiwan-roc-road-sign");

    // By sign code
    const s = getSignByCode("A1");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/tw';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function TWGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/tw';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { TWSign, TWCategory } from '@road-signs/tw';

type TWCategory =
  | 'information'
  | 'mandatory'
  | 'prohibitory'
  | 'warning';

interface TWSign {
  id: string;          // e.g. "w1-sharp-bend"
  code: string;        // sign code, e.g. "W1"
  name: string;
  description: string;
  category: TWCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
