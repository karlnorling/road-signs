The `@road-signs/gr` package contains Greek road signs from the **ΚΟΚ (Κώδικας Οδικής Κυκλοφορίας)**, the Greek road traffic code.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/gr
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | ΚΟΚ series Κ | Hazard warnings — triangular |
| `priority` | — | Right-of-way and stop signs |
| `prohibitory` | ΚΟΚ series Ρ | Prohibitions and regulatory restrictions |
| `mandatory` | — | Compulsory actions |
| `information` | ΚΟΚ series Π | Information and direction signs |

    ```ts
    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("k1-sharp-bend");
    ```

    ```tsx
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>

      );
    }
    ```

## TypeScript types

```ts
import type { GRSign, GRCategory } from '@road-signs/gr';

type GRCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface GRSign {
  id: string;          // e.g. "k1-sharp-bend"
  code: string;        // sign code, e.g. "K1"
  name: string;
  description: string;
  category: GRCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
