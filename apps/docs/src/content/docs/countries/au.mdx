The `@road-signs/au` package contains Australia road signs from the **AS1742 Manual of Uniform Traffic Control Devices (MUTCD)**, the national standard governing road signs across Australian states and territories.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/au
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | W series | Diamond-shaped hazard warnings — yellow/black |
| `priority` | — | Give way and stop signs |
| `prohibitory` | R series | Regulatory restrictions — white/red |
| `mandatory` | — | Compulsory direction signs — blue |
| `information` | — | Information, direction, and tourist signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/au';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("w1-1-curves-ahead");

    // By sign code
    const s = getSignByCode("W1-1");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/au';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```

        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>

## TypeScript types

```ts
import type { AUSign, AUCategory } from '@road-signs/au';

type AUCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface AUSign {
  id: string;          // e.g. "w1-1-curves-ahead"
  code: string;        // e.g. "W1-1"
  name: string;
  description: string;
  category: AUCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
