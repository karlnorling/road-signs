The `@road-signs/es` package contains Spain road signs from the **Reglamento General de Circulación**, using P/R/S/M series codes.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/es
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | P series | Peligro (danger) signs — triangular, red border |
| `priority` | P series (priority) | Right-of-way and stop signs |
| `prohibitory` | R series | Reglamentación (regulatory) — circular, red/blue |
| `mandatory` | M series | Maniobra (manoeuvre) signs — circular, blue |
| `information` | S series | Information and direction signs — rectangular |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/es';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("p-1a-dangerous-bend");

    // By sign code
    const s = getSignByCode("P-1a");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/es';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>

        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>

## TypeScript types

```ts
import type { ESSign, ESCategory } from '@road-signs/es';

type ESCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface ESSign {
  id: string;          // e.g. "p-1a-dangerous-bend"
  code: string;        // Series code, e.g. "P-1a"
  name: string;
  description: string;
  category: ESCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
