The `@road-signs/uk` package contains UK road signs as defined in the
**Traffic Signs Regulations and General Directions 2016 (TSRGD)**. Signs are
identified by their TSRGD diagram numbers and sourced from Wikipedia / Wikimedia
Commons. The [Highway Code traffic signs guide](https://www.gov.uk/guidance/the-highway-code/traffic-signs)
is the authoritative reference for sign meanings and legal obligations.

## Installation

```sh
npm install @road-signs/uk
```

## Sign categories

| Category | TSRGD part | Description |
| -------- | ---------- | ----------- |
| `warning` | Part 3 | Hazard warnings — triangular, red border |
| `regulatory` | Part 2 | Signs giving orders — circular, red/blue |
| `direction` | Part 4 | Route and destination signs — rectangular, colour by road type |
| `information` | Part 5 | Informatory signs — rectangular |
| `temporary` | Part 7 | Road works and temporary signs — rectangular, orange/yellow |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/uk';

    // All signs
    signs.length;

    // By slug ID
    const noEntry = getSign('601-no-entry');

    // By TSRGD diagram number
    const stop = getSignByCode('602');

    // All warning signs
    const warnings = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/uk';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/uk';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { UKSign, UKCategory } from '@road-signs/uk';

type UKCategory =
  | 'direction'
  | 'information'
  | 'regulatory'
  | 'temporary'
  | 'warning';

interface UKSign {
  id: string;        // e.g. "601-no-entry"
  code: string;      // TSRGD diagram number, e.g. "601"
  name: string;      // e.g. "No Entry"
  description: string;
  category: UKCategory;
  svg: string;       // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
