{/* QUICK_FACTS:END */}

The `@road-signs/pl` package contains Poland road signs from the **Prawo o ruchu drogowym**, using A/B/C/D/E/F/G series.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/pl
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Ostrzegawcze (warning) — triangular, red border |
| `priority` | A series (priority) | Pierwszeństwo (right-of-way) signs |
| `prohibitory` | B series | Zakazu (prohibition) — circular, red border |
| `mandatory` | C series | Nakazu (obligation) — circular, blue background |
| `information` | D / E / F series | Informacyjne (information) and direction signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/pl';

    // Example below uses the real PL sign "A-1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a-1-dangerous-curve-to-the-right");

    // By sign code
    const s = getSignByCode("A-1");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/pl';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function PLGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/pl';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { PLSign, PLCategory } from '@road-signs/pl';

type PLCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface PLSign {
  id: string;          // e.g. "a-1-dangerous-bend"
  code: string;        // Series code, e.g. "A-1"
  name: string;
  description: string;
  category: PLCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
