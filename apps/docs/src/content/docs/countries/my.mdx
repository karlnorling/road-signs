The `@road-signs/my` package contains Malaysia road signs from the **Road Transport (Traffic Signs) Rules 1959 — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/my
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Regulatory | Regulatory and prohibition signs |
| `mandatory` | Instruction | Mandatory instruction signs |
| `information` | Guide / Temporary | Guide and information signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/my';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("example-sign");

    // By sign code
    const s = getSignByCode("W1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/my';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/my';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
