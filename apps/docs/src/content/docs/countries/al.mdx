The `@road-signs/al` package contains Albanian road signs from the **Kodi Rrugor — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/al
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Paralajmëruese — hazard warnings |
| `priority` | B series | Prioriteti — right-of-way |
| `prohibitory` | C series | Ndaluese dhe kufizuese — prohibitions |
| `mandatory` | D series | Detyruese — mandatory actions |
| `information` | E–F series | Informuese — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/al';

    // Example below uses the real AL sign "E852" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("e852-european-road-number-sign");

    // By sign code
    const s = getSignByCode("E852");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/al';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function ALGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/al';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { ALSign, ALCategory } from '@road-signs/al';

type ALCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface ALSign {
  id: string;          // e.g. "a1-sharp-bend"
  code: string;        // sign code, e.g. "A1"
  name: string;
  description: string;
  category: ALCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
