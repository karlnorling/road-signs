{/* QUICK_FACTS:END */}

The `@road-signs/cz` package contains Czech Republic road signs under **zákon č. 361/2000 Sb.**
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/cz
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Výstražné značky — hazard warnings |
| `priority` | B series | Značky upravující přednost — right-of-way |
| `prohibitory` | B/C series | Zákazové a příkazové značky — prohibitions and restrictions |
| `mandatory` | C series | Příkazové značky — compulsory actions |
| `information` | IP/IJ/IS series | Informativní značky — information and service |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/cz';

    // Example below uses the real CZ sign "I-1A" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("i-1a-i-1a-dangerous-curve-to-the-right");

    // By sign code
    const s = getSignByCode("I-1A");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/cz';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function CZGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/cz';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>

## TypeScript types

```ts
import type { CZSign, CZCategory } from '@road-signs/cz';

type CZCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface CZSign {
  id: string;          // e.g. "a1-sharp-bend"
  code: string;        // sign code, e.g. "A1"
  name: string;
  description: string;
  category: CZCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
