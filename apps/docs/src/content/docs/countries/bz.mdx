The `@road-signs/bz` package contains Belize road signs (UK-influenced / SIECA).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/bz
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service / Additional | Information, service, and additional plate signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/bz';

    // Example below uses the real BZ sign "E1-1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("e1-1-sieca-road-sign-assembly-e3-3");

    // By sign code
    const s = getSignByCode("E1-1");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/bz';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function BZGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/bz';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
