The `@road-signs/nz` package contains New Zealand road signs from the **Traffic Control Devices Rule (NZTA)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/nz
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard warnings |
| `regulatory` | Regulatory | Regulatory signs |
| `mandatory` | Mandatory | Mandatory actions |
| `information` | Information | Information and direction |
| `temporary` | Temporary | Temporary traffic management |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/nz';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("w1-sharp-bend");

    // By sign code
    const s = getSignByCode("W1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/nz';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { getSignsByCategory } from '@road-signs/nz';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { NZSign, NZCategory } from '@road-signs/nz';

type NZCategory =
  | 'information'
  | 'mandatory'
  | 'regulatory'
  | 'temporary'
  | 'warning';

interface NZSign {
  id: string;          // e.g. "w1-sharp-bend"
  code: string;        // sign code, e.g. "W1"
  name: string;
  description: string;
  category: NZCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
