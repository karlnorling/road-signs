The `@road-signs/li` package contains Liechtenstein road signs under the **SSV/SVV (Swiss Sign Ordinance) — Vienna Convention**.
Liechtenstein uses Swiss-standard signs (SSV/SVV) — the sign set is effectively identical to `@road-signs/ch`.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/li
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 1.xx | Hazard warnings |
| `priority` | 2.xx | Right-of-way signs |
| `prohibitory` | 3.xx | Prohibitions and restrictions |
| `mandatory` | 4.xx | Mandatory actions |
| `information` | 5–6.xx | Information and direction |

    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/li';
    ```

    ```tsx
    import { RoadSign } from '@road-signs/react';

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (

          ))}
        </div>
      );
    }
    ```

## TypeScript types

```ts
import type { LISign, LICategory } from '@road-signs/li';

type LICategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface LISign {
  id: string;          // e.g. "1-01-sharp-bend"
  code: string;        // sign code, e.g. "1.01"
  name: string;
  description: string;
  category: LICategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
