The `@road-signs/is` package contains Iceland road signs from the **Umferðarlög — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/is
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Viðvörun — hazard warnings |
| `priority` | B series | Forgangur — right-of-way |
| `prohibitory` | C series | Bönn og takmarkanir — prohibitions |
| `mandatory` | D series | Skylda — mandatory actions |
| `information` | E–F series | Upplýsingar — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/is';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a1-sharp-bend");

    // By sign code
    const s = getSignByCode("A1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/is';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">

    ```vue
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { ISSign, ISCategory } from '@road-signs/is';

type ISCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface ISSign {
  id: string;          // e.g. "a1-sharp-bend"
  code: string;        // sign code, e.g. "A1"
  name: string;
  description: string;
  category: ISCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
