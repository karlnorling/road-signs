The `@road-signs/th` package contains Thailand road signs from the **Land Traffic Act (พระราชบัญญัติจราจรทางบก)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/th
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | ป้ายเตือน — hazard warnings |
| `prohibitory` | Regulatory | ป้ายบังคับ — regulatory and prohibitory signs |
| `mandatory` | Instruction | ป้ายบังคับ (คำสั่ง) — mandatory instruction signs |
| `information` | Guide | ป้ายแนะนำ — guide and information signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/th';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("w1-sharp-bend");

    // By sign code
    const s = getSignByCode("W1");

    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/th';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```

        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>

## TypeScript types

```ts
import type { THSign, THCategory } from '@road-signs/th';

type THCategory =
  | 'information'
  | 'mandatory'
  | 'prohibitory'
  | 'warning';

interface THSign {
  id: string;          // e.g. "w1-sharp-bend"
  code: string;        // sign code, e.g. "W1"
  name: string;
  description: string;
  category: THCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
