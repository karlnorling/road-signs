The `@road-signs/ao` package contains Angola road signs (Vienna Convention / Portuguese-influenced).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/ao
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A — Warning | Hazard and warning signs |
| `priority` | B — Priority | Priority and right-of-way signs |
| `prohibitory` | C — Prohibitory | Prohibition and restriction signs |
| `mandatory` | D — Mandatory | Mandatory instruction signs |
| `information` | H / M — Information | Information and additional signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/ao';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("example-sign");

    // By sign code
    const s = getSignByCode("A1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/ao';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/ao';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
