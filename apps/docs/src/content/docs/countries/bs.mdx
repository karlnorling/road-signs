The `@road-signs/bs` package contains Bahamas road signs (British-derived).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/bs
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service | Information and service signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/bs';

    // Example below uses the real BS sign "bahamas-no-entry" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("bahamas-no-entry-bahamas-no-entry");

    // By sign code
    const s = getSignByCode("bahamas-no-entry");

    // All priority signs
    const filtered = getSignsByCategory("priority");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/bs';
    import { RoadSign } from '@road-signs/react';

    const prioritySigns = getSignsByCategory("priority");

    export default function BSGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {prioritySigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/bs';
    import { RoadSign } from '@road-signs/vue';

    const prioritySigns = getSignsByCategory("priority");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in prioritySigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
