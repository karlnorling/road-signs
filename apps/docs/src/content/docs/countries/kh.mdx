## Quick facts

| Field | Value |
| ----- | ----- |
| Drive side | Right-hand |
| Language(s) | Khmer |
| Regulator | MPWT |
| Standard | Vienna Convention (Prakas on Road Signs 2014) |

{/* QUICK_FACTS:END */}

The `@road-signs/kh` package contains Cambodia road signs from the **European + MUTCD hybrid** standard.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/kh
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Regulatory | Regulatory and prohibition signs |
| `mandatory` | Mandatory | Mandatory instruction signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/kh';

    // Example below uses the real KH sign "AH1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("ah1-k");

    // By sign code
    const s = getSignByCode("AH1");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/kh';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function KHGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/kh';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
