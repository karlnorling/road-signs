The `@road-signs/ch` package contains Switzerland road signs from the **Signalisationsverordnung (SVV/SSV)**, Switzerland's signage ordinance which follows the Vienna Convention.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/ch
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 1.xx | Gefahrensignale — hazard warnings |
| `priority` | 2.xx | Vortrittssignale — right-of-way |
| `prohibitory` | 3.xx | Verbotssignale — prohibitions |
| `mandatory` | 4.xx | Gebotssignale — compulsory actions |
| `information` | 5–6.xx | Hinweissignale — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/ch';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("1-01-danger-bend-right");

    // By sign code
    const s = getSignByCode("1.01");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/ch';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>

    ```vue
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { CHSign, CHCategory } from '@road-signs/ch';

type CHCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface CHSign {
  id: string;          // e.g. "1-01-danger-bend-right"
  code: string;        // e.g. "1.01"
  name: string;
  description: string;
  category: CHCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
