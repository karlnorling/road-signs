The `@road-signs/co` package contains Colombian road signs from the **Manual de Señalización Vial (MSV/INVIAS) — Vienna Convention variant**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/co
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Preventivas | Señales preventivas — hazard warnings |
| `prohibitory` | Reglamentarias | Señales reglamentarias — prohibitions and regulations |
| `information` | Informativas | Señales informativas — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/co';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("sp1-sharp-bend");

    // By sign code
    const s = getSignByCode("SP-1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/co';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { COSign, COCategory } from '@road-signs/co';

type COCategory =
  | 'information'
  | 'prohibitory'
  | 'warning';

interface COSign {
  id: string;          // e.g. "sp1-sharp-bend"
  code: string;        // sign code, e.g. "SP-1"
  name: string;
  description: string;
  category: COCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
