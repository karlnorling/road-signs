The `@road-signs/nl` package contains Netherlands road signs from the **Reglement verkeersregels en verkeerstekens (RVV 1990)**, using A–L series.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/nl
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A / J series | Gevaar (danger) signs — triangular or diamond |
| `priority` | B series | Voorrang (priority) signs — stop, yield |
| `prohibitory` | C series | Verbod (prohibition) signs — circular, red border |
| `mandatory` | D / E series | Gebod (obligation) signs — circular, blue |
| `information` | F / G series | Aanwijzing (indication) and direction signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/nl';

    // Example below uses the real NL sign "J1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("j1-uneven-road");

    // By sign code
    const s = getSignByCode("J1");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/nl';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function NLGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/nl';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { NLSign, NLCategory } from '@road-signs/nl';

type NLCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface NLSign {
  id: string;          // e.g. "a1-maximum-speed"
  code: string;        // RVV code, e.g. "A1"
  name: string;
  description: string;
  category: NLCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
