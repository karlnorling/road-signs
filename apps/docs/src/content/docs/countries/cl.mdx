The `@road-signs/cl` package contains Chilean road signs from the **Manual de Señalización de Tránsito (DGOP/MOP) — Vienna variant**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/cl
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Preventivas | Señales preventivas — hazard warnings |
| `prohibitory` | Reglamentarias | Señales reglamentarias — prohibitions and regulations |
| `information` | Informativas | Señales informativas — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/cl';

    // Example below uses the real CL sign "PG-1A" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("pg-1a-pg-1a-gentle-curve-to-the-right");

    // By sign code
    const s = getSignByCode("PG-1A");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/cl';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function CLGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/cl';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { CLSign, CLCategory } from '@road-signs/cl';

type CLCategory =
  | 'information'
  | 'prohibitory'
  | 'warning';

interface CLSign {
  id: string;          // e.g. "p1-sharp-bend"
  code: string;        // sign code, e.g. "P1"
  name: string;
  description: string;
  category: CLCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
