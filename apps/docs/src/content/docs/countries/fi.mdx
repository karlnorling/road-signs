The `@road-signs/fi` package contains Finland road signs from the **Tieliikennelaki**, Finland's road traffic act which follows the Vienna Convention.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/fi
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 111–199 | Warning signs |
| `priority` | 211–299 | Right-of-way signs |
| `prohibitory` | 311–399 | Prohibition signs |
| `mandatory` | 411–499 | Mandatory signs |
| `information` | 511+ | Information and guide signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/fi';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("111-dangerous-bend");

    // By sign code
    const s = getSignByCode("111");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/fi';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>

    ```vue
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { FISign, FICategory } from '@road-signs/fi';

type FICategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface FISign {
  id: string;          // e.g. "111-dangerous-bend"
  code: string;        // e.g. "111"
  name: string;
  description: string;
  category: FICategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
