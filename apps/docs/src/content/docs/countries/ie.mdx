The `@road-signs/ie` package contains Ireland road signs from the **Road Traffic (Signs) Regulations**, Ireland's statutory instrument governing road signage.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/ie
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | W series | Diamond/square hazard warnings |
| `priority` | — | Yield and stop signs |
| `prohibitory` | — | Regulatory restrictions |
| `mandatory` | — | Compulsory actions |
| `information` | — | Information, direction, and tourist signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/ie';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("w-01-bend-ahead");

    // By sign code
    const s = getSignByCode("W-01");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/ie';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { IESign, IECategory } from '@road-signs/ie';

type IECategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface IESign {
  id: string;          // e.g. "w-01-bend-ahead"
  code: string;        // e.g. "W-01"
  name: string;
  description: string;
  category: IECategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
