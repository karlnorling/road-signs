The `@road-signs/no` package contains Norway road signs from the **Skiltforskriften**, Norway's road sign regulations which follow the Vienna Convention.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/no
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 1xx | Advarselsskilt — hazard warnings |
| `priority` | 2xx | Vikepliktsskilt — right-of-way |
| `prohibitory` | 3xx | Forbudsskilt — prohibitions |
| `mandatory` | 4xx | Påbudsskilt — compulsory actions |
| `information` | 5–7xx | Opplysningsskilt — information signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/no';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("104-dangerous-bend");

    // By sign code
    const s = getSignByCode("104");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/no';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/no';
    import { RoadSign } from '@road-signs/vue';

    const warnings = getSignsByCategory('warning');
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { NOSign, NOCategory } from '@road-signs/no';

type NOCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface NOSign {
  id: string;          // e.g. "104-dangerous-bend"
  code: string;        // e.g. "104"
  name: string;
  description: string;
  category: NOCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
