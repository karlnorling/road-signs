The `@road-signs/kr` package contains South Korean road signs from the **Road Traffic Act (도로교통법)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/kr
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 주의표지 | Jui pyoji — hazard warnings |
| `prohibitory` | 규제표지 | Gyuje pyoji — regulatory prohibitions |
| `mandatory` | 지시표지 | Jisi pyoji — instruction and mandatory actions |
| `information` | 안내표지 | Annae pyoji — guide and information |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/kr';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("101-intersection-ahead");

    // By sign code
    const s = getSignByCode("101");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/kr';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```

        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>

## TypeScript types

```ts
import type { KRSign, KRCategory } from '@road-signs/kr';

type KRCategory =
  | 'information'
  | 'mandatory'
  | 'prohibitory'
  | 'warning';

interface KRSign {
  id: string;          // e.g. "101-intersection-ahead"
  code: string;        // sign code, e.g. "101"
  name: string;
  description: string;
  category: KRCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
