The `@road-signs/lu` package contains Luxembourg road signs from the **Code de la route — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/lu
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Danger — hazard warnings |
| `priority` | B series | Priorité — right-of-way |
| `prohibitory` | C series | Interdictions et restrictions — prohibitions |
| `mandatory` | D series | Obligations — mandatory actions |
| `information` | E–F series | Indication — information and direction |

## TypeScript types

```ts
import type { LUSign, LUCategory } from '@road-signs/lu';

type LUCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface LUSign {
  id: string;          // e.g. "a1-sharp-bend"
  code: string;        // sign code, e.g. "A1"
  name: string;
  description: string;
  category: LUCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
