The `@road-signs/za` package contains South African road signs from the **SARTSM (South African Road Traffic Signs Manual)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/za
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | W series | Hazard warnings |
| `regulatory` | R series | Regulatory and prohibitory signs |
| `guidance` | G series | Guidance and information |
| `temporary` | T series | Temporary traffic management |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/za';

    // Example below uses the real ZA sign "stop-3-way" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("stop-3-way-stop-3-way");

    // By sign code
    const s = getSignByCode("stop-3-way");

    // All prohibitory signs
    const filtered = getSignsByCategory("prohibitory");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/za';
    import { RoadSign } from '@road-signs/react';

    const prohibitorySigns = getSignsByCategory("prohibitory");

    export default function ZAGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {prohibitorySigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/za';
    import { RoadSign } from '@road-signs/vue';

    const prohibitorySigns = getSignsByCategory("prohibitory");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in prohibitorySigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { ZASign, ZACategory } from '@road-signs/za';

type ZACategory =
  | 'guidance'
  | 'regulatory'
  | 'temporary'
  | 'warning';

interface ZASign {
  id: string;          // e.g. "w1-sharp-bend"
  code: string;        // sign code, e.g. "W1"
  name: string;
  description: string;
  category: ZACategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
