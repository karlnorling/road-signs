The `@road-signs/at` package contains Austria road signs from the **Straßenverkehrs-Ordnung (StVO)**, Austria's road traffic regulation which follows the Vienna Convention.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/at
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Gefahrenzeichen | Hazard warnings |
| `priority` | Vorrangzeichen | Right-of-way signs |
| `prohibitory` | Verbotszeichen | Prohibitions and restrictions |
| `mandatory` | Gebotszeichen | Compulsory actions |
| `information` | Hinweiszeichen | Information and direction signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/at';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a1-danger-bend-right");

    // By sign code
    const s = getSignByCode("A1");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/at';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>

    ```vue
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { ATSign, ATCategory } from '@road-signs/at';

type ATCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface ATSign {
  id: string;          // e.g. "a1-danger-bend-right"
  code: string;        // e.g. "A1"
  name: string;
  description: string;
  category: ATCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
