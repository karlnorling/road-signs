The `@road-signs/eg` package contains Egypt road signs from the **British-derived (ETSM)** standard.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/eg
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `priority` | Priority | Priority and right-of-way signs |
| `prohibitory` | Prohibitory / Regulatory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/eg';

    // Example below uses the real EG sign "egyptian-road-sign-stop" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("egyptian-road-sign-stop-egyptian-road-sign-stop");

    // By sign code
    const s = getSignByCode("egyptian-road-sign-stop");

    // All priority signs
    const filtered = getSignsByCategory("priority");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/eg';
    import { RoadSign } from '@road-signs/react';

    const prioritySigns = getSignsByCategory("priority");

    export default function EGGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {prioritySigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/eg';
    import { RoadSign } from '@road-signs/vue';

    const prioritySigns = getSignsByCategory("priority");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in prioritySigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
