The `@road-signs/mz` package contains Mozambique road signs (Vienna Convention / Portuguese-influenced).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/mz
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service / Additional | Information, service, and additional plate signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/mz';

    // Example below uses the real MZ sign "R101-600" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("r101-600-sadc-road-sign");

    // By sign code
    const s = getSignByCode("R101-600");

    // All mandatory signs
    const filtered = getSignsByCategory("mandatory");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/mz';
    import { RoadSign } from '@road-signs/react';

    const mandatorySigns = getSignsByCategory("mandatory");

    export default function MZGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {mandatorySigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/mz';
    import { RoadSign } from '@road-signs/vue';

    const mandatorySigns = getSignsByCategory("mandatory");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in mandatorySigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
