The `@road-signs/se` package contains Swedish road signs as defined in the
**Vägmärkesförordning (Road Signs Ordinance, SFS 2007:90)**, supplemented by
TSFS 2019:74. Signs are sourced from Wikipedia / Wikimedia Commons and are in
the public domain.

## Installation

```sh
npm install @road-signs/se
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Warn of hazards ahead — triangular, yellow background |
| `priority` | B series | Right-of-way and yield — stop sign, yield, priority road |
| `prohibitory` | C series | Prohibitions and restrictions — circular, red border |
| `mandatory` | D series | Compulsory actions — circular, blue background |
| `information` | E–I series | Information, directions, and services — rectangular |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/se';

    // Example below uses the real SE sign "F1-1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("f1-1-f1-1");

    // By sign code
    const s = getSignByCode("F1-1");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/se';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function SEGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/se';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { SESign, SECategory } from '@road-signs/se';

type SECategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface SESign {
  id: string;        // e.g. "a1-curve-right"
  code: string;      // e.g. "A1"
  name: string;      // e.g. "Curve Right"
  description: string;
  category: SECategory;
  svg: string;       // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
