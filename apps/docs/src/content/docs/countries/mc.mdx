The `@road-signs/mc` package contains Monaco road signs (Vienna Convention (Code de la route) — shared with France).
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/mc
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Warning | Hazard and warning signs |
| `prohibitory` | Prohibitory | Prohibition and restriction signs |
| `mandatory` | Mandatory | Mandatory instruction signs |
| `information` | Information / Service / Additional | Information, service, and additional plate signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/mc';

    // Example below uses the real MC sign "30-km-h-zone" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("30-km-h-zone-30-km-h-zone");

    // By sign code
    const s = getSignByCode("30-km-h-zone");

    // All prohibitory signs
    const filtered = getSignsByCategory("prohibitory");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/mc';
    import { RoadSign } from '@road-signs/react';

    const prohibitorySigns = getSignsByCategory("prohibitory");

    export default function MCGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {prohibitorySigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/mc';
    import { RoadSign } from '@road-signs/vue';

    const prohibitorySigns = getSignsByCategory("prohibitory");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in prohibitorySigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>
</Tabs>
