The `@road-signs/de` package contains Germany road signs from the **Straßenverkehrs-Ordnung (StVO)**, identified by Zeichen (sign) numbers.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/de
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Gefahrenzeichen | Hazard warnings — triangular, yellow/black |
| `priority` | Vorfahrtzeichen | Right-of-way, stop, and yield signs |
| `prohibitory` | Verbotszeichen | Prohibitions and restrictions — circular, red border |
| `mandatory` | Gebotszeichen | Compulsory actions — circular, blue background |
| `information` | Hinweiszeichen | Information, directions, and services — rectangular |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/de';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("101-danger-bend-right");

    // By sign code
    const s = getSignByCode("101");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/de';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { DESign, DECategory } from '@road-signs/de';

type DECategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface DESign {
  id: string;          // e.g. "101-danger-bend-right"
  code: string;        // Zeichen number, e.g. "101"
  name: string;
  description: string;
  category: DECategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
