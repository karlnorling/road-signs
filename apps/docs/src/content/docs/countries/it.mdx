{/* QUICK_FACTS:END */}

The `@road-signs/it` package contains Italy road signs from the **Codice della Strada**, identified by figure numbers (fig. II.1, fig. III.5).
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/it
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | fig. II series | Danger signs — triangular, red border |
| `priority` | fig. II (precedenza) | Precedence and right-of-way signs |
| `prohibitory` | fig. III series | Prohibition signs — circular, red border |
| `mandatory` | fig. IV series | Obligation signs — circular, blue background |
| `information` | fig. V–VI series | Indication and direction signs — rectangular |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/it';

    // Example below uses the real IT sign "A1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("a1-beginning-of-a-danger-or-a-prescription-vertical");

    // By sign code
    const s = getSignByCode("A1");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/it';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function ITGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/it';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { ITSign, ITCategory } from '@road-signs/it';

type ITCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface ITSign {
  id: string;          // e.g. "ii-1-curve-ahead"
  code: string;        // Figure number, e.g. "II.1"
  name: string;
  description: string;
  category: ITCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
