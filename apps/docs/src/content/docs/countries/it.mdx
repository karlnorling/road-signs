The `@road-signs/it` package contains Italy road signs from the **Codice della Strada**, identified by figure numbers (fig. II.1, fig. III.5).
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/it
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | fig. II series | Danger signs — triangular, red border |
| `priority` | fig. II (precedenza) | Precedence and right-of-way signs |
| `prohibitory` | fig. III series | Prohibition signs — circular, red border |
| `mandatory` | fig. IV series | Obligation signs — circular, blue background |
| `information` | fig. V–VI series | Indication and direction signs — rectangular |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/it';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("ii-1-curve-ahead");

    // By sign code
    const s = getSignByCode("II.1");

    // All prohibitory signs
    const filtered = getSignsByCategory('prohibitory');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/it';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { ITSign, ITCategory } from '@road-signs/it';

type ITCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface ITSign {
  id: string;          // e.g. "ii-1-curve-ahead"
  code: string;        // Figure number, e.g. "II.1"
  name: string;
  description: string;
  category: ITCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
