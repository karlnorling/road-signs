The `@road-signs/jp` package contains Japan road signs from the **Road Traffic Law (道路交通法)**, Japan's national road traffic legislation.
Signs are sourced from Wikipedia / Wikimedia Commons. Signs are in the public domain.

## Installation

```sh
npm install @road-signs/jp
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | 2xx | 警戒標識 — hazard warnings |
| `prohibitory` | 1xx | 規制標識 — regulatory signs |
| `mandatory` | 3xx | 指示標識 — instruction signs |
| `information` | 4xx | 案内標識 — guide signs |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/jp';

    // Example below uses the real JP sign "E1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("e1-expressway-number-tomei");

    // By sign code
    const s = getSignByCode("E1");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/jp';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function JPGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/jp';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { JPSign, JPCategory } from '@road-signs/jp';

type JPCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface JPSign {
  id: string;          // e.g. "201-dangerous-bend"
  code: string;        // e.g. "201"
  name: string;
  description: string;
  category: JPCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
