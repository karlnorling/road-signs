The `@road-signs/cy` package contains Cypriot road signs from the **Road Traffic Law (Cap. 332) — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/cy
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Hazard warnings |
| `priority` | B series | Right-of-way signs |
| `prohibitory` | C series | Prohibitions and restrictions |
| `mandatory` | D series | Mandatory actions |
| `information` | E–F series | Information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/cy';

    // Example below uses the real CY sign "V5-1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("v5-1-allowed-only-for-disabled-vehicles");

    // By sign code
    const s = getSignByCode("V5-1");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/cy';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function CYGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/cy';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { CYSign, CYCategory } from '@road-signs/cy';

type CYCategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface CYSign {
  id: string;          // e.g. "a1-sharp-bend"
  code: string;        // sign code, e.g. "A1"
  name: string;
  description: string;
  category: CYCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
