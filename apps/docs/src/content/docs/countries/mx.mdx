The `@road-signs/mx` package contains Mexican road signs from the **SCT (Secretaría de Comunicaciones y Transportes)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/mx
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Preventivas | Hazard warnings |
| `prohibitory` | Restrictivas | Prohibitions and restrictions |
| `information` | Informativas | Information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/mx';

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("p1-sharp-bend");

    // By sign code
    const s = getSignByCode("P-1");

    // All warning signs
    const filtered = getSignsByCategory('warning');
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/mx';
    import { RoadSign } from '@road-signs/react';

    const warnings = getSignsByCategory('warning');

    export default function WarningGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warnings.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue

    import { RoadSign } from '@road-signs/vue';

    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warnings" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```

## TypeScript types

```ts
import type { MXSign, MXCategory } from '@road-signs/mx';

type MXCategory =
  | 'information'
  | 'prohibitory'
  | 'warning';

interface MXSign {
  id: string;          // e.g. "p1-sharp-bend"
  code: string;        // sign code, e.g. "P-1"
  name: string;
  description: string;
  category: MXCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
