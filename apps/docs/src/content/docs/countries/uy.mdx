The `@road-signs/uy` package contains Uruguayan road signs from the **Decreto 374/004 — Reglamento Nacional de Tránsito (Vienna Convention variant)**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/uy
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | Preventivas | Señales preventivas — hazard warnings |
| `prohibitory` | Reglamentarias | Señales reglamentarias — prohibitions and regulations |
| `information` | Informativas | Señales informativas — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/uy';

    // Example below uses the real UY sign "P1A" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("p1a-uruguay-road-sign-p1a");

    // By sign code
    const s = getSignByCode("P1A");

    // All information signs
    const filtered = getSignsByCategory("information");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/uy';
    import { RoadSign } from '@road-signs/react';

    const informationSigns = getSignsByCategory("information");

    export default function UYGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {informationSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/uy';
    import { RoadSign } from '@road-signs/vue';

    const informationSigns = getSignsByCategory("information");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in informationSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { UYSign, UYCategory } from '@road-signs/uy';

type UYCategory =
  | 'information'
  | 'prohibitory'
  | 'warning';

interface UYSign {
  id: string;          // e.g. "p1-sharp-bend"
  code: string;        // sign code, e.g. "P1"
  name: string;
  description: string;
  category: UYCategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
