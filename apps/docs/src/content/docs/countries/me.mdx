The `@road-signs/me` package contains Montenegro road signs from the **Zakon o bezbjednosti saobraćaja na putevima — Vienna Convention**.
Signs are sourced from Wikimedia Commons and are in the public domain.

## Installation

```sh
npm install @road-signs/me
```

## Sign categories

| Category | Series | Description |
| -------- | ------ | ----------- |
| `warning` | A series | Upozoravajući znaci — hazard warnings |
| `priority` | B series | Znaci prednosti prolaza — right-of-way |
| `prohibitory` | C series | Zabrane i ograničenja — prohibitions |
| `mandatory` | D series | Obaveze — mandatory actions |
| `information` | E–F series | Obavještavajući znaci — information and direction |

## Usage

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { signs, getSign, getSignByCode, getSignsByCategory } from '@road-signs/me';

    // Example below uses the real ME sign "I-1" — adjust to taste.

    // All signs
    signs.length;

    // By slug ID
    const sign = getSign("i-1-left-curve");

    // By sign code
    const s = getSignByCode("I-1");

    // All warning signs
    const filtered = getSignsByCategory("warning");
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    import { getSignsByCategory } from '@road-signs/me';
    import { RoadSign } from '@road-signs/react';

    const warningSigns = getSignsByCategory("warning");

    export default function MEGrid() {
      return (
        <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
          {warningSigns.map((sign) => (
            <RoadSign key={sign.id} sign={sign} size={64} />
          ))}
        </div>
      );
    }
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { getSignsByCategory } from '@road-signs/me';
    import { RoadSign } from '@road-signs/vue';

    const warningSigns = getSignsByCategory("warning");
    </script>

    <template>
      <div style="display:flex;gap:8px;flex-wrap:wrap">
        <RoadSign v-for="sign in warningSigns" :key="sign.id" :sign="sign" :size="64" />
      </div>
    </template>
    ```
  </TabItem>

## TypeScript types

```ts
import type { MESign, MECategory } from '@road-signs/me';

type MECategory =
  | 'information'
  | 'mandatory'
  | 'priority'
  | 'prohibitory'
  | 'warning';

interface MESign {
  id: string;          // e.g. "a1-sharp-bend"
  code: string;        // sign code, e.g. "A1"
  name: string;
  description: string;
  category: MECategory;
  svg: string;         // inline SVG string
  assets: {
    svg: string;
    png: Record<number, string>;
    jpg: Record<number, string>;
    webp: Record<number, string>;
  };
}
```
